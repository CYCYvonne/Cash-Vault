# Supabase Setup

The database tables and Row Level Security policies were applied to this Supabase project:

- Project ref: `itmczwqpgmvuaaktireb`
- Project URL: `https://itmczwqpgmvuaaktireb.supabase.co`

To connect the website:

1. Open Supabase Dashboard.
2. Go to Project Settings > API.
3. Copy the public `anon` / publishable key.
4. Open `supabase-config.js`.
5. Replace `PASTE_YOUR_SUPABASE_ANON_KEY_HERE` with that key.

The website will stay in local mode until the anon key is added. After that, users can create an account, sign in, and sync wallets/transactions to Supabase.

Database schema is saved in `supabase-schema.sql`.
